## 🛠️ Tools & Technologies Used

- **Microsoft Power BI Desktop**: Report design, DAX measures, data modeling, custom visuals, slicers, and interactive cards.
- **Power Query**: Data cleaning, transformations, typecasting, and schema modeling.
- **DAX (Data Analysis Expressions)**: Aggregations, rankings, conditional logic, time intelligence, and KPI metrics.
- **Data Modeling**: Star schema and relational design across fact and dimension tables.

## 💻 How to View These Reports

1. Clone this repository:
   ```bash
   git clone https://github.com/irfan-shekh/Power_BI_Projects.git
   ```
2. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) if you haven't already.
3. Navigate into the specific project folder and open the `.pbix` file.
